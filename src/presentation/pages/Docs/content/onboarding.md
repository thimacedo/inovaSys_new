# 🚀 Guia de Início Rápido

Bem-vindo ao **InovaSys**, a plataforma de excelência para gestão de Câmaras de Arbitragem.

## 🏁 Primeiros Passos
1. **Configuração de Perfil:** Acesse as configurações e complete seus dados profissionais e CPF.
2. **Registro de Câmara:** Se você é um administrador, cadastre sua organização para ativar o faturamento.
3. **Primeiro Protocolo:** Utilize o botão "Novo Processo" para iniciar um litígio.

## 🛠️ Ferramentas Principais
- **Timeline:** Acompanhe cada etapa do processo em tempo real.
- **LegalOps:** Automação de minutas e controle de prazos.
- **Financeiro:** Gestão de custas e honorários integrada ao Supabase.

> **Dica:** Utilize o comando de voz no dashboard para atalhos rápidos de navegação.
