# InovaSys - ERP & Gestão (Core)

## Escopo do Projeto
Este diretório contém o código-fonte do InovaSys, um sistema de gestão ERP focado em:
- Gestão de Câmaras Municipais e Órgãos Públicos.
- Gestão Financeira e Auditoria.
- Controle de Assinaturas e Planos.
- Gestão de Equipe.

## Regras de Engajamento para IA
1. **Foco em Gestão:** Não utilize ferramentas de inteligência política ou extração de redes sociais neste contexto.
2. **Schema do Banco:** Utilize prioritariamente o schema `public` para tabelas de gestão.
3. **Padrão de Código:** Siga o Clean Code e os princípios SOLID estabelecidos no projeto React/Vite.
